# Matching pair

A LogTen export and a ForeFlight export of the same small, synthetic logbook, for testing the
audit. They disagree on purpose:

| Date       | What differs                                       |
| ---------- | -------------------------------------------------- |
| 2024-03-01 | Rounding only (1.28 h against 1.3 h)               |
| 2024-03-02 | Night time (0.8 h against 0.3 h)                   |
| 2024-03-04 | Tail number (N404GH against N414GH), plus rounding |
| 2024-03-05 | Nothing                                            |
| 2024-03-10 | A simulator session that is only in ForeFlight     |
| 2024-03-12 | A ground-training session that is only in LogTen   |
